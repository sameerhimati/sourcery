Search APIs, graded on their sources

Benchmarks of search APIs grade the answer a model writes afterwards. That number is mostly a score of the model. This one never sees an answer. Eight providers got the same 204 questions on one day; Claude Sonnet 5, GPT-5.6 and GLM 5.2 read every page that came back and scored it — 22,457 ratings across 7,496 pages.

The ranking, and where it stops being one

Each provider returned eight pages per question. A judge saw all eight and answered one thing: could someone answer from these alone? Zero is nothing useful, three is a full answer.

Perplexity is clear of everyone. Below it, two groups and no order inside either. Ask the same questions next week and the members of each group could come back in a different sequence.

The step between the groups is real. Exa to Tavily is four tenths of a rung — bigger than anything inside either cluster, and the only place in the table where the choice changes what you get.

The blunter version of the same result: Perplexity returns a page that fully answers the question 49.9% of the time. Bright Data manages 14.9%. That ordering matches the one above, so nothing here depends on the 0–3 scale being right.

Easy questions hide the difference

Half the set was written to be hard — multi-hop, ambiguous, or needing a source that is not the first result.

Benchmark search on questions your model could nearly answer already and every provider looks fine. The difference only appears on the ones you actually needed help with.

Price buys nothing

The three providers sharing the cheapest tier take three of the top four places. The outright cheapest places sixth. Price predicts nothing in either direction.

Serper matches Tavily's score at a fifty-fourth of the cost, which makes sense once you know it returns links and snippets and never page content. If you already run a scraper, that is the part you were paying extra for.

“Page text” means something different to each of them

Brave is the one to look at. It ranks second and returns real page text on one per cent of results — its content is search snippets joined together. Fine for grounding a summary, useless to an agent that has to read a document. Exa keeps headings and drops links. Bright Data keeps nearly every image and no tables.

The other axis is volume. An agent gives each source a slice of its context, and this run allows 1600 characters — a realistic budget. 98% of Firecrawl's pages run past it; 40% of Perplexity's do. Firecrawl returns whole documents and Perplexity returns excerpts, and past the budget that difference stops reaching the model.

Why this disagrees with the answer-graded index

Artificial Analysis published a search index the day before this went out. It ranks Firecrawl third. This puts it seventh. That is not a contradiction — the two measure different things.

They grade what an agent eventually produces. Their harness gives a model up to 25 turns and roughly nine to thirteen searches per task, then scores the final answer. A weak first set of results gets repaired by searching again. This grades what one search hands back. Eight results, one shot, no recovery.

Their questions are static obscure facts. These lean fresh. Different retrieval problems.

Neither index rewards Firecrawl's extraction, for opposite reasons. Their settings disable its scraping by name and route every provider through one generic extractor. This run asked for full page markdown and got it, and then each source met a per-source context budget that most of those pages exceed. The advantage is real and it sits upstream of where either benchmark can see it.

Their index also carries no confidence intervals, and their top five span two points. On their published sample sizes that gap sits inside the noise — the same reason three providers here are shown as a tie rather than as first, second and third.

What to use

Perplexitybest overall

Clear of the field and on the cheapest tier. Fully answers 49.9% of the time, about 1.4× anyone else. Also the easiest of the eight to fool — see below.

Serperbest value

Tavily's score at a fifty-fourth of the price. Links and snippets only. Pair it with your own fetch.

Firecrawlhardest to fool

On the 12 questions with no answer it produced the fewest convincing near-misses, beating Perplexity on all 12. Read alongside its seventh place: a provider that finds less also invents less.

Braveread the fine print

Ranks second on relevance and returns snippets, not pages. Right for grounding a summary, wrong for an agent that reads documents.

The trade-off worth naming: Perplexity is the best of the eight at finding real answers and the worst at not manufacturing the appearance of one. Asked for a Postgres setting that does not exist, one arm returned a page about a real setting with a similar name and a judge called it a direct answer. A miss is visible. A confident near-miss is not.

What varies

One question goes to all eight providers. Each returns up to 8 results. Nothing else differs between arms — same prompt, same judges, same number of results requested, same day, caching off.

The settings live in one file, core/controls.ts, and every stage imports from it. A setting that exists in two places is a setting that will eventually differ between two arms.

The two rubrics

Both ask the same question at two scopes, on the same four rungs. Two models can agree on a named rung; a bare number on a wide scale is something each one invents its own version of.

Page rating — does this page help?

One question, one page. The judge is never told which provider returned it, never shown an answer, and never asked to write one.

Both prompts are in core/controls.ts in full. The set prompt replaced an earlier one partway through the run, which graded whether sources looked good — fresh, authoritative, cleanly extracted. On a question with no answer anywhere it returned a passing score while the page judge rated every page 0 or 1. The sources were good. They just could not answer.

Pooling

Providers overlap heavily. Every page from every arm is collapsed into one pool keyed by normalized URL and graded once; that rating counts for each provider that returned it. 66.8% of the 7,496 pages came from exactly one provider and 24 came from all eight.

This blinds the judge structurally rather than by promise — a page is detached from whoever returned it before grading, so there is no provider name to be swayed by. The cost is that where several arms returned the same URL, the longest extraction anyone returned is what gets graded, so extraction quality is averaged away on those pages.

The statistics, in words

Confidence interval

Where the real value probably sits, given that 204 questions is a sample. Two overlapping intervals mean the order between those providers is not a finding.

Variance shares

How much of everything that varies is explained by each thing that could explain it. The provider explains 23.1%; which judge you picked explains 2.2%.

Kappa

Agreement between two judges after subtracting the agreement you would get by chance. These three run 0.51 to 0.55 — they agree on the order and argue about the decimals.

Sign test

Comparing two providers across the same small set of questions by counting wins, then asking how often a split that lopsided would happen by luck. Used on the 12 unanswerable questions, where eight providers cannot be ranked but two can be compared.

What this cannot tell you

Who extracts a page best

Each source gets a 1600-character slice, which is what an agent with a real context budget would allow. Providers that return whole documents therefore have most of that document sitting past the line. Measuring extraction properly means holding the URLs fixed and varying only the extractor, and that run has not happened.

What your agent will answer

Nothing here grades an answer, on purpose. An answer-graded benchmark measures that, bearing in mind such a number also grades your model.

How any of this behaves at scale

Bright Data throttles above one concurrent request. Tavily's plan ran out around question 150. Firecrawl burned 3,493 credits in a day — it requests web and news results, which bills twice, and only the web half becomes sources; the news half buys publish dates. A keyless control arm was dropped after eight consecutive captcha failures. The run cost $40.08 and the ceiling was a rate limit long before it was money.

Whether the questions look like yours

204 questions written to probe retrieval, not collected from real traffic: 96 ordinary, 96 deliberately hard, 12 with no answer at all. Frozen and public, so you can judge the resemblance — and the harness exists so you can run your own instead.

Every rating is published with the sentence the judge wrote to justify it. Any number here traces back to the verdict that produced it.
